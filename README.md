### 🌾 KhetGPT

**Multi-Agent AI for Indian Farmers**

</div>

An agricultural AI platform designed to bring specialized AI capabilities together for farmer assistance.

- FastAPI backend for agricultural services.
- Crop-then-disease classification pipeline with EfficientNetB0.
- Multi-agent query routing using LangChain/LangGraph and Groq's Llama 3.3.
- Weather, mandi-price, and government-scheme guidance.
- Docker-based deployment workflow.

**Stack:** Python · FastAPI · TensorFlow · LangGraph · Groq · Docker

### 🍃 Kisan AI

**Crop Disease Detection**

</div>

A multilingual crop disease detection application focused on making image-based plant diagnosis accessible.

- Fine-tuned EfficientNetB0 on the PlantVillage dataset.
- Model covers 38 disease classes.
- Streamlit interface with English, Hindi, and Hinglish.
- Deployed on Hugging Face Spaces.

**Stack:** Python · TensorFlow · Keras · Streamlit

### 🧠 AI Study Buddy

**RAG-Based Q&A over Personal Notes**

</div>

A retrieval-augmented question-answering system that retrieves relevant content from personal notes and uses an LLM to generate responses.

- Built a retrieval pipeline using LangChain and ChromaDB.

- Containerized the application with Docker.

**Stack:** LangChain · ChromaDB · Sentence Transformers · Groq · Docker
